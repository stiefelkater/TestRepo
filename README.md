# Kevin Explains Your Generation

An animated, voiced web page: Kevin, a Gen X dolphin with a mullet and laser eyes, spends about two minutes explaining why the current generation falls short of Gen X.

## Run it

Serve the folder rather than opening the file directly:

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

Press **Play tape**. Space toggles play/pause. The chapter buttons jump to any of the nine segments.

## How the sync works

- `audio/scene1.mp3` through `audio/scene9.mp3` were generated with ElevenLabs (model `eleven_v3`, voice "Darby Skelm"), one clip per segment.
- Each segment starts when the previous clip fires `ended`, so segment boundaries are exact.
- `timing.js` is generated by `tools/analyze_audio.py`. It holds each clip's duration, a mouth-open envelope sampled every 40 ms (drives Kevin's jaw), and caption start times.
- Caption and laser cue times are aligned to detected speech onsets and weighted by syllable count. They are estimates and can land a fraction of a second early or late on some lines.
- Clips play at 1.2x speed with pitch preserved, for a runtime of 2:13.

To regenerate timing after replacing a clip:

```sh
pip install miniaudio numpy
python3 tools/analyze_audio.py
```
